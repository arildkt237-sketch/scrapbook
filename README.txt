WEBSITE SCRAPBOOK ROMANTIS
==========================

CARA MENJALANKAN
1. Ekstrak file ZIP.
2. Buka folder website_bucin_scrapbook.
3. Klik dua kali index.html, atau buka folder di VS Code lalu jalankan dengan Live Server.

CARA MENGGANTI FOTO
1. Buka folder assets.
2. Ganti foto-1.jpg, foto-2.jpg, foto-3.jpg, foto-4.jpg dengan foto milikmu.
3. Gunakan nama file yang sama agar tidak perlu mengubah HTML.
4. Foto sebaiknya berbentuk portrait agar pas di bingkai.

CARA MENGGANTI MUSIK
1. Masukkan file musik berformat MP3 ke folder assets.
2. Namai file tersebut musik.mp3.
3. Musik baru bisa diputar setelah tombol "Putar musik" ditekan.

CARA MENGGANTI PESAN
Buka script.js, lalu edit teks di dalam const pesanSurat.

CARA MENGGANTI CAPTION / CERITA / NAMA / TANGGAL
Buka index.html, lalu ubah tulisan yang ada di bagian galeri dan timeline.

CATATAN
- Website memakai Google Fonts dan gambar cadangan dari Unsplash; koneksi internet diperlukan untuk memuatnya.
- Musik tidak otomatis menyala karena browser biasanya memblokir autoplay.
- Foto lokal di folder assets akan dipakai jika file tersedia.
